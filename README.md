# Reignsound.org — Homepage MVP

A responsive, static-first homepage implementation based on the approved Reignsound landing-page mockup. Reignsound is positioned as an independent enterprise operating through a conglomeration of brands. Uses the IBM Plex Sans, Serif, and Mono font families and a custom inline SVG landscape so the main illustration remains crisp at all viewport sizes.

## Preview locally

Open `index.html` directly in a browser, or serve this directory with any static web server. Google Fonts require an internet connection; the page falls back to system sans-serif fonts if unavailable.

## Before launch

- Confirm the correct GitHub repository and Vercel project for `reignsound.org`.
- Replace the provisional documentation provenance details with the canonical release/commit metadata during deployment.
- Configure the real contact address and review all public brand names/marks.
- Donation/payment functionality is intentionally inactive; the support section communicates that contribution options are being prepared.
- Review legal/entity and charitable-solicitation language before accepting contributions or implying tax deductibility.
