# Changelog

All notable, intentional changes to the Reignsound.org website are documented here. Entries distinguish content, design, and implementation changes so they can be reviewed alongside the Git history.

## 2026-10-26

### Homepage content

- **Contribution section heading:** Changed “Join Reignsound™:” to “Contribute to Reignsound™:”. The revised wording better fits the section’s invitation to participate and avoids the visual distraction caused by the capital “J” in the IBM Plex typeface.
- **People. Planet. Progress. introduction:** Updated the opening to “Reignsound™ is a future-forward company that supports charitable efforts…” while retaining the existing references to universal well-being, universal accessibility, strategic partnerships, innovative solutions, and sustainable resource development.
